# 📧 Email Assistant Backend

This is the backend service for **Email Assistant**, a Chrome extension that helps generate AI-powered replies to Gmail messages using **Google’s Gemini 2.0 Flash API**.  

The backend is built with **Spring Boot**, exposes a simple REST API, and connects to Gemini to generate context-aware, tone-adjusted email replies.

---

## 🚀 Features
- REST API endpoint to generate AI-based replies  
- Integration with **Google Gemini 2.0 Flash API**  
- Supports different tones (friendly, formal, professional, etc.)  
- Easy to integrate with the Chrome Extension frontend  

---

## 🛠️ Tech Stack
- **Java 21**
- **Spring Boot 3+**
- **Maven**
- **Google Gemini 2.0 Flash API**
- **REST APIs**
